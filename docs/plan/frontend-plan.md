> 三章放同一份文件，是因为一个页面从上到下的决策要能在一屏里看见彼此。

# 第一章 IA（信息架构）

## 1.1 页面清单与路由

| 路由 | 页面 | 让人完成的动作（不是「显示什么」） | 功能 |
|---|---|---|---|
| `/` | 工具列表 | 一眼看完四个工具各自什么状态，判断哪个需要我动手 | F-06 |
| `/tools/:id` | 工具详情 | 确认它现在到底连哪个供应商/模型，然后换一个 | F-07 |
| `/presets` | 预设管理 | 维护我常用的几组「供应商+模型」，供切换时挑 | F-04 |
| `/chat` | 对话 | 选一个工具和目录，说一句话，看它边跑边回 | F-08 |
| `/history` | 历史 | 找回过之前跑过的会话，只读回看 | F-12、F-13 |
| `/styleguide` | 设计自检 | 确认所有 tokens 与组件全状态长什么样，只在开发时看 | F-14 |

六个页面，但只有四个是「用户会自己走到的」，另外两个是工具页。

## 1.2 导航

```text
┌──────────────────────────────────────────────┐
│ 顶栏：产品名  |  工具   对话   历史   [设置] │
└───────┬──────────────────────────────────────┘
        │
        ├─ 工具 (/)
        │    └─ 工具详情 (/tools/:id)
        │           └─ 换预设时侧滑「变更预览」抽屉（不独立成页）
        ├─ 预设 (/presets)      ← 顶栏「工具」页内的次要入口，不进主导航
        ├─ 对话 (/chat)         ← 对话内可跳到该会话历史
        └─ 历史 (/history)      └─ 会话回放 (/history/:id)
```

决策：**预设管理不做一级页面**，它是「工具详情页」右上角的一个入口 + 独立路由。
理由：预设永远是在「我要换模型」这个动作里被用到的，把它平铺到主导航会让人以为它是主角。

## 1.3 每页的信息层级

**工具列表（/）** —— 一行一个工具，行内三层：状态点 + 工具名 → 当前 provider·model → 配置路径（次要色）
排序按固定顺序 Claude Code / Codex CLI / Gemini CLI / OpenCode，**不按状态排**（位置稳定才扫得快）。

**工具详情（/tools/:id）** —— 从上到下：路径与打开方式 → 当前配置四项 → 换成哪个预设 → diff → 确认按钮。
只做一件危险动作（写入），所以确认按钮放最下面，视觉上离「返回」最远。

**预设管理（/presets）** —— 一个表格：名称 / 供应商 / 模型 / 密钥引用 / 操作。新建走右侧抽屉。

**对话（/chat）** —— 左侧会话列表（可收起）、中间消息流、顶部上下文条、底部输入框。
上下文条永远可见，因为「我现在在跟哪个模型说话」是这个页面最容易搞错的事。

**历史（/history）** —— 左列表右只读回放；回放区顶部一条横幅「这是回放，不能继续输入」。

## 1.4 状态矩阵

工具四态见 `docs/plan/plan.md` 第 6 节，**不在这里重复**。这里只补对话页的状态：

| 对话状态 | 表现 | 能否输入 |
|---|---|---|
| 未选工具 | 空状态：一排工具卡片让你点一个 | 否 |
| 已选工具·空闲 | 输入框可用 | 是 |
| 流式输出中 | 最后一条消息带光标动效，「发送」变「停止」 | 否（只能停止） |
| 进程已退出 | 消息流末尾一行灰色「进程已退出（code 0）」 | 是 |
| 进程异常退出 | 同上但红色，带最后 3 行 stderr | 是 |
| 工具不可用（未安装/未配置） | 输入框禁用 + 一行指向详情页的链接 | 否 |

## 1.5 空状态与错误状态清单（写组件前必须都有答案）

| 位置 | 空状态文案 | 错误状态 |
|---|---|---|
| 工具列表 | 「没有检测到任何工具」+ 四个工具的安装说明链接 | 读取失败时整页降级成一条红条，不显示半张表 |
| 工具详情 | —（详情页一定有工具 id） | 解析失败：红条 + 首行错误 + 禁写，其余字段显示「—」 |
| 预设管理 | 「还没有预设」+ 一个「新建」按钮 | 保存失败：抽屉不关，字段下标红 |
| 对话 | 「选一个工具开始」 | 见 1.4 |
| 历史 | 「还没有会话」 | 「这个工具的历史读不到」（L2 常见） |

# 第三章 tokens

落地文件：`frontend/src/styles/tokens.css`。组件里只允许引用变量，不允许裸数值。

## 3.1 间距刻度（只允许这七档）

```css
--sp-1: 4px;  --sp-2: 8px;  --sp-3: 12px; --sp-4: 16px;
--sp-5: 24px; --sp-6: 32px; --sp-7: 48px;
```

## 3.2 字号阶梯（只允许这五档）

| 变量 | 值 | 行高 | 用途 |
|---|---|---|---|
| `--fs-xs` | 12px | 1.5 | 路径、时间戳、次要说明 |
| `--fs-sm` | 13px | 1.5 | 表格、列表行 |
| `--fs-md` | 14px | 1.6 | 正文（默认） |
| `--fs-lg` | 16px | 1.4 | 页面标题 |
| `--fs-xl` | 20px | 1.3 | 空状态的标题 |

字体栈：`system-ui, "Segoe UI", "Microsoft YaHei", sans-serif`；代码/路径用
`ui-monospace, "Cascadia Code", Consolas, monospace`。

## 3.3 颜色（只用语义名，不写十六进制）

```css
--bg:         #1b1b1f;   /* 页面底 */
--surface:    #232327;   /* 卡片、列表行 */
--surface-2:  #2b2b31;   /* 输入框、抽屉 */
--border:     #35353c;   /* 1px 分隔 */
--border-strong: #4a4a54;/* 输入框聚焦前 */
--text:       #e6e6e9;
--text-dim:   #9a9aa3;   /* 次要信息 */
--accent:     #4c8dff;   /* 唯一强调色：主按钮、选中、聚焦环 */
--accent-fg:  #ffffff;   /* 强调色上的文字 */
--ok:         #3fb950;   /* 状态点：已配置 */
--warn:       #d29922;   /* 状态点：配置有误 */
--danger:     #f85149;   /* 危险按钮、错误条 */
```

虚线之外加一条规则：**深色为默认**。这是开发者工具，跟随系统主题在收口卡再补。

## 3.4 圆角与边框

```css
--r-sm: 4px;  --r-md: 6px;  --r-lg: 10px;
--bw: 1px;
--focus-ring: 0 0 0 2px var(--accent);
```

阴影只用一处：抽屉与对话框 `--shadow-overlay: 0 8px 32px rgb(0 0 0 / 45%)`。其余一律不加阴影。

## 3.5 三条硬规则（004 卡写进 `guards.py` 或 lint）

1. `.vue` / `.css` 里出现 `px` 字面量，必须是 0 或在 `tokens.css` 内。
2. 出现 `#` 开头的十六进制颜色，只允许在 `tokens.css` 内。
3. 组件不直接调 `fetch`，只走 `src/api/`（已有规则，此处重申）。

## 3.6 组件只做三个（v1）

`Button`（primary / ghost / danger 三态）、`Field`（label + input + 错误行）、`Dialog`（遮罩 + 抽屉/居中两种）。
其余全用原生元素 + tokens。第四个组件出现时先讨论，不直接加。
